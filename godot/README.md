# Vertex Racing: Nitro Rush — Godot

هذه بداية نسخة Godot من اللعبة، منفصلة عن نسخة JavaScript الحالية.

## التشغيل
افتح مجلد `godot` في Godot 4.x ثم شغل `main.tscn`.

## التحكم
- W / ↑ تسارع
- S / ↓ فرامل
- A D / ← → توجيه
- Space نيترو
- Shift درفت

## الموجود حالياً
- سباق 3D كامل بمسار طويل.
- سيارة لاعب بتسارع وتوجيه ودرفت.
- نيترو وتأثير إضاءة.
- 3 منافسين.
- مباني وأعمدة إنارة وحواجز.
- واجهة سرعة، نيترو، مركز وتقدم السباق.
- خط نهاية ونتيجة سباق.

المرحلة التالية: موديلات سيارات أعلى جودة، خامات PBR، مؤثرات دخان وشرر، رامبات واصطدامات أقوى.
